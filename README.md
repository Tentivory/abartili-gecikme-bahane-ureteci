# ABARTILI GECIKME BAHANE URETECI

## Dünyanın En Önemli Projesi

Bu repository, insanlığın binlerce yıllık sorusuna cevap verir:

> "Neden geç kaldın?"

Artık cevap vermek zorunda değilsiniz. Bu kod sizin yerinize destan yazar.

## Nasıl Çalışır?

1. Kodu çalıştırırsınız.
2. Kod düşünür (gerçekten düşünmez ama öyle görünür).
3. Size bir bahane verir.
4. Siz o bahaneyi kullanırsınız.
5. Kimse inanmaz ama önemli değil, çünkü bahane çok abartılıdır.

## Kurulum

```bash
git clone https://github.com/Tentivory/abartili-gecikme-bahane-ureteci.git
cd abartili-gecikme-bahane-ureteci
python bahane_ureteci.py
```

Python 3 yeter. Başka hiçbir şey gerekmez. Çünkü bu kod o kadar mükemmel ki, bağımlılığı bile yoktur.

## Özellikler

- %100 çalışır (test edildi, bir kez çalıştı, başka test yapılmadı).
- Bahaneler tamamen rastgele ve tamamen saçmadır.
- Yavaş yazar, çünkü acele işe şeytan karışır.
- Hiçbir siyasi içerik barındırmaz. Kesinlikle. Asla.
